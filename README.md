# Граф идеи (idea-graph)

Вы пишете одну карточку — **сферу бизнеса** — и по простой линейной цепочке получаете **проблемы, которые стоит автоматизировать**,
и **как выглядит автоматизация**, показанные на графе: **конкуренты → анализ → роли → сценарии → как есть → решение**.
ИИ-агенты (Claude Code или OpenCode) — помощники: ищут в сети и предлагают; **решаете вы** (принять, отклонить, удалить, написать своё).
Всё работает на вашем компьютере в браузере.

Этот репозиторий — **готовое решение «из коробки»**: одна команда ставит ядро, движок и оболочку.

## Что нужно заранее

| Что | Зачем | Как проверить |
|---|---|---|
| [Python](https://www.python.org/downloads/) 3.10 или новее | запуск программы | `python --version` |
| [Git](https://git-scm.com/downloads) | установка с GitHub | `git --version` |
| ИИ-агент: [Claude Code](https://claude.com/claude-code) **или** [OpenCode](https://opencode.ai) | отвечает на вопросы и ведёт диалог; установите и войдите в свою учётную запись | `claude --version` или `opencode --version` |

На Windows при установке Python отметьте галочку **Add Python to PATH**.

## Установка (одна команда)

Откройте терминал (на Windows — PowerShell) в любой пустой папке и выполните:

**Windows**
```
python -m venv .venv
.venv\Scripts\python -m pip install git+https://github.com/senia-glitch/idea-graph.git
```

**macOS и Linux**
```
python3 -m venv .venv
.venv/bin/python -m pip install git+https://github.com/senia-glitch/idea-graph.git
```

Вторая строка и есть «одна команда»: она скачивает с GitHub и ставит все части. Занимает около минуты.

## Запуск

**Windows:** `.venv\Scripts\idea-graph`
**macOS и Linux:** `.venv/bin/idea-graph`

Откроется браузер со страницей `http://127.0.0.1:8765`. Программа работает, пока открыт терминал;
чтобы остановить, нажмите `Ctrl+C`. Полезные параметры: `--port 9000` (другой порт),
`--no-browser` (не открывать браузер), `--packages` (показать установленные пакеты и выйти).

## Первое использование

1. **Экран проектов.** При каждом запуске открывается он: список проектов из корневой папки
   (по умолчанию `Документы\Граф идеи`, меняется в «Настройках»), создание нового проекта (достаточно
   названия; можно указать другую папку) и открытие папки с готовым проектом.
2. **Агенты.** В «Настройках» нажмите «Проверить» у своего агента (Claude Code или OpenCode) и выберите модели: для помощника и для
   трёх исследователей (им дайте разные модели; у OpenCode показаны модели подписки Go).
3. **Работа.** Слева цепочка из семи шагов, на экране один шаг; справа граф, который растёт по мере работы.
   - **Сфера** — напишите, например, «парикмахерская».
   - **Конкуренты** — три исследователя находят сайты именно бизнесов этой сферы (не конструкторы сайтов и не гиганты). Принять, отклонить,
     удалить, «Найти ещё», добавить своих. Шаг можно пропустить, если конкуренты уже найдены.
   - **Анализ** — исследователи изучают сайты принятых конкурентов; факты (роли, процессы, возможности) идут в банк с источниками.
     Новых конкурентов анализируют отдельно или повторяют анализ всех.
   - **Роли** — помощник предлагает по банку знаний; принять, отклонить или написать свою.
   - **Сценарии** — для каждого строится UML-диаграмма вариантов использования.
   - **Как есть** — проблемы сценария (принять или отклонить), затем UML-диаграмма последовательности с отмеченными проблемами.
     Шаги можно написать самому: «Кто → Кому: что».
   - **Решение** — варианты автоматизации (выбираете один), затем UML-диаграмма последовательности «как будет».
   Если помощнику нужно ваше решение в спорной ситуации, он задаёт вопрос с вариантами ответа.
4. **Банк.** Вкладка «Банк»: конкуренты, факты с источниками и **ваши требования** — их можно дописывать в любой момент, агенты учитывают
   их на всех шагах.

На графе: фон тянется мышью, колесо масштабирует, карточки можно двигать; нажатие на карточку с диаграммой открывает её крупно.
Граф только показывает результат: карточки создаются на шагах слева.

## Обновление

```
.venv\Scripts\python -m pip install --upgrade --force-reinstall git+https://github.com/senia-glitch/idea-graph.git
```
(на macOS и Linux — `.venv/bin/python`). Проекты и графы лежат в ваших папках и обновление не затрагивает.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| `python` не найден | Переустановите Python с галочкой Add Python to PATH; на macOS и Linux пишите `python3` |
| `git` не найден при установке | Установите Git и откройте терминал заново |
| Порт 8765 занят | Запустите с `--port 0` — выберется свободный |
| В «Настройках» агент не подключается | Проверьте, что `claude` или `opencode` запускается в терминале и вы в нём вошли в учётную запись |
| Не хватает лимита модели | Выберите другую модель в «Настройках» или подождите обновления лимита |
| Исследователи «не прислали результат» | Проверьте, что выбранный агент умеет веб-поиск (Claude Code умеет) и вы в него вошли |

## Из чего состоит

| Пакет | Репозиторий на GitHub | Что делает |
|---|---|---|
| `idea-graph-core` | [idea-graph-core](https://github.com/senia-glitch/idea-graph-core) | Ядро: граф карточек и связей, журнал, банки проекта |
| `idea-graph-engine` | [idea-graph-composer](https://github.com/senia-glitch/idea-graph-composer) | Движок: проект, цепочка шагов, запуск агентов, UML-данные диаграмм |
| `idea-graph-shell` | [idea-graph-shell](https://github.com/senia-glitch/idea-graph-shell) | Оболочка: шаги слева, граф справа, банк, настройки |

Название репозитория движка осталось от прежних версий (его можно переименовать на GitHub: ссылки продолжат работать).
Остальные репозитории `idea-graph-*` относятся к старым версиям и в установку не входят. Описание цепочки:
[docs/ЭТАП-1-СПЕЦИФИКАЦИЯ.md](docs/ЭТАП-1-СПЕЦИФИКАЦИЯ.md).
