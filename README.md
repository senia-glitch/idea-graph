# Граф идеи (idea-graph)

Помогает пройти путь от сферы бизнеса до решения, что и как автоматизировать: **разведка конкурентов → роли → сценарии →
выбор для автоматизации → «как есть» с болями → вид автоматизации → «как будет»**, с диаграммами. ИИ-агенты (Claude Code или OpenCode) —
помощники: предлагают, проверяют, уточняют, ищут в сети; **решаете вы**. Всё работает на вашем компьютере в браузере.

Этот репозиторий — **готовое решение «из коробки»**: одна команда ставит ядро, движок, оболочку и два этапа.

## Что нужно заранее

| Что | Зачем | Как проверить |
|---|---|---|
| [Python](https://www.python.org/downloads/) 3.10 или новее | запуск программы | `python --version` |
| [Git](https://git-scm.com/downloads) | установка с GitHub | `git --version` |
| ИИ-агент: [Claude Code](https://claude.com/claude-code) **или** [OpenCode](https://opencode.ai) | отвечает на вопросы и ведёт диалог; установите и войдите в свою учётную запись | `claude --version` или `opencode --version` |

На Windows при установке Python отметьте галочку **Add Python to PATH**.

## Установка (одна команда)

Откройте терминал (на Windows — PowerShell) в любой пустой папке и выполните:

**Windows**
```
python -m venv .venv
.venv\Scripts\python -m pip install git+https://github.com/senia-glitch/idea-graph.git
```

**macOS и Linux**
```
python3 -m venv .venv
.venv/bin/python -m pip install git+https://github.com/senia-glitch/idea-graph.git
```

Вторая строка и есть «одна команда»: она скачивает с GitHub и ставит все части. Занимает около минуты.

## Запуск

**Windows:** `.venv\Scripts\idea-graph`
**macOS и Linux:** `.venv/bin/idea-graph`

Откроется браузер со страницей `http://127.0.0.1:8765`. Программа работает, пока открыт терминал;
чтобы остановить, нажмите `Ctrl+C`. Полезные параметры: `--port 9000` (другой порт),
`--no-browser` (не открывать браузер), `--packages` (показать установленные пакеты и выйти).

## Первое использование

1. **Экран проектов.** При каждом запуске открывается он: список проектов из корневой папки
   (по умолчанию `Документы\Граф идеи`, меняется в «Настройках»), создание нового проекта (достаточно
   названия; можно указать другую папку) и открытие папки с готовым проектом.
2. **Агенты.** В «Настройках» нажмите «Подключить» у своего агента (Claude Code или OpenCode) и выберите модели: для помощника,
   для трёх исследователей, для трёх советников и для ревьюера (дайте им разные модели; у OpenCode показаны модели подписки Go).
3. **Сфера.** Нажмите «+ Сфера» и напишите сферу бизнеса, подлежащую автоматизации. Сферы пишете только вы, корневой карточки нет.
4. **Карта этапа.** Вкладка показывает шаги этапа цепочкой. На каждом шаге: «Предложить» (агент создаёт предложенные карточки или
   задаёт вопрос с вариантами в чате справа), «Проверить» (независимый ревьюер оставляет замечания), «Уточнить» (поиск неточностей),
   «Утвердить» (ворота: вы закрываете шаг). Этап «Разведка» ищет и анализирует конкурентов в общий банк, «Процессы» ведёт от ролей к
   диаграмме «как будет». Ресурсы (ссылки, текстовые файлы) добавляйте во вкладке «Ресурсы» справа: их читают исследователи.
5. **Автоматический режим (необязательно).** «⚡ Авто» проходит шаги этапа без ваших вопросов: на развилках решает совет из трёх
   агентов, а краткое обоснование попадает в карточку. Результат остаётся «предложенным»: вы принимаете и правите его.
6. **Правки.** Карточки можно править, удалять, перетаскивать и связывать в любой момент; ваша правка главнее правки агента.
   Если вы изменили карточку утверждённого шага, зависимые шаги помечаются «требует пересмотра», а помощник предлагает правки
   (карточки «правка»: применить или отклонить).

На холсте: фон тянется мышью, колесо масштабирует, «+» рядом с карточкой создаёт потомка,
кружок ○ в заголовке тянется к другой карточке (новая связь), «Отменить» в шапке откатывает
последнее изменение, вкладка «История» возвращает удалённое.

## Обновление

```
.venv\Scripts\python -m pip install --upgrade --force-reinstall git+https://github.com/senia-glitch/idea-graph.git
```
(на macOS и Linux — `.venv/bin/python`). Проекты и графы лежат в ваших папках и обновление не затрагивает.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| `python` не найден | Переустановите Python с галочкой Add Python to PATH; на macOS и Linux пишите `python3` |
| `git` не найден при установке | Установите Git и откройте терминал заново |
| Порт 8765 занят | Запустите с `--port 0` — выберется свободный |
| В «Настройках» агент не подключается | Проверьте, что `claude` или `opencode` запускается в терминале и вы в нём вошли в учётную запись |
| Не хватает лимита модели | Выберите другую модель в «Настройках» или подождите обновления лимита |

## Из чего состоит

| Пакет | Репозиторий на GitHub | Что делает |
|---|---|---|
| `idea-graph-core` | [idea-graph-core](https://github.com/senia-glitch/idea-graph-core) | Ядро: граф карточек и связей, журнал, отмена, банки проекта |
| `idea-graph-engine` | [idea-graph-composer](https://github.com/senia-glitch/idea-graph-composer) | Движок: запуск агентов, ворота шагов, совет, ревью, исследователи, правки зависимого |
| `idea-graph-shell` | [idea-graph-shell](https://github.com/senia-glitch/idea-graph-shell) | Оболочка: экран проектов, карта этапа, холст, чат, настройки |
| `idea-graph-recon` | [idea-graph-research](https://github.com/senia-glitch/idea-graph-research) | Этап «Разведка»: сфера, конкуренты, анализ, банк |
| `idea-graph-processes` | [idea-graph-problem](https://github.com/senia-glitch/idea-graph-problem) | Этап «Процессы»: роли, сценарии, выбор, как есть и как будет |

Названия репозиториев остались от прежних версий; в таблице — какой пакет в каком репозитории лежит (их можно переименовать на GitHub:
ссылки продолжат работать). Остальные репозитории `idea-graph-*` (clarify, check, decider, export, formalize, handoff) относятся к старой
версии и в установку не входят.

Каждая часть — отдельный Python-пакет. Новый этап — это пакет с точкой входа `idea_graph.packages` и декларацией шагов; правок движка и
оболочки он не требует (пример — `idea-graph-recon`). Принятые решения: [docs/ЭТАП-1-СПЕЦИФИКАЦИЯ.md](docs/ЭТАП-1-СПЕЦИФИКАЦИЯ.md).
