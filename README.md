# Граф идеи (idea-graph)

Превращает сырую идею в проработанный граф решений и требований — через диалог с ИИ-агентом,
который задаёт по одному вопросу с готовыми вариантами ответа. Результат можно выгрузить в документ
или передать в разработку. Всё работает на вашем компьютере в браузере.

Этот репозиторий — **готовое решение «из коробки»**: одна команда ставит все десять частей системы.

## Что нужно заранее

| Что | Зачем | Как проверить |
|---|---|---|
| [Python](https://www.python.org/downloads/) 3.10 или новее | запуск программы | `python --version` |
| [Git](https://git-scm.com/downloads) | установка с GitHub | `git --version` |
| ИИ-агент: [Claude Code](https://claude.com/claude-code) **или** [OpenCode](https://opencode.ai) | отвечает на вопросы и ведёт диалог; установите и войдите в свою учётную запись | `claude --version` или `opencode --version` |

На Windows при установке Python отметьте галочку **Add Python to PATH**.

## Установка (одна команда)

Откройте терминал (на Windows — PowerShell) в любой пустой папке и выполните:

**Windows**
```
python -m venv .venv
.venv\Scripts\python -m pip install git+https://github.com/senia-glitch/idea-graph.git
```

**macOS и Linux**
```
python3 -m venv .venv
.venv/bin/python -m pip install git+https://github.com/senia-glitch/idea-graph.git
```

Вторая строка и есть «одна команда»: она скачивает с GitHub и ставит все части. Занимает около минуты.

## Запуск

**Windows:** `.venv\Scripts\ideagraph`
**macOS и Linux:** `.venv/bin/ideagraph`

Откроется браузер со страницей `http://127.0.0.1:8765`. Программа работает, пока открыт терминал;
чтобы остановить, нажмите `Ctrl+C`. Полезные параметры: `--port 9000` (другой порт),
`--no-browser` (не открывать браузер), `--packages` (показать установленные пакеты и выйти).

## Первое использование

1. **Идея.** На экране «Идеи» введите идею одной строкой и выберите папку, где она будет жить.
   Одна идея — одна папка; граф хранится в её подпапке `.ideagraph`.
2. **Агент.** Откройте «Настройки», нажмите «Подключить» у своего агента (Claude Code или OpenCode)
   и выберите модель для каждого пакета. Двум решателям стоит дать разные модели.
3. **Уточнение.** На экране «Граф» выберите пакет «Уточнение идеи» и нажмите «Запустить».
   Агент задаст вопрос: выберите вариант, напишите своё или отклоните все. Ответы становятся карточками.
4. **Правки.** Карточки можно править, удалять, перетаскивать и связывать в любой момент.
   Ваша правка главнее правки агента.
5. **Дальше.** Запускайте другие пакеты: «Проверка графа» найдёт противоречия, дубли и пробелы,
   «Исследование» соберёт конкурентов и факты, «Формализация требований» превратит решения в требования.
6. **Результат.** «Выгрузка в документ» создаёт читаемый документ `idea.md`, «Передача в студию» — файл `studio-ideas.json`
   для pacage-studio-ide.
7. **Автопилот (по желанию).** Переключатель «На вопросы отвечает: Я / Решатель» отдаёт ответы агенту-решателю.
   Его решения помечены на карточках и собраны во вкладке «Решения агента»; любое можно переопределить.
   Экран «Конвейер» — карта пакетов, которую можно пройти по шагам или автоматически.

На холсте: фон тянется мышью, колесо масштабирует, «+» рядом с карточкой создаёт потомка,
кружок ○ в заголовке тянется к другой карточке (новая связь), «Отменить» в шапке откатывает
последнее изменение, вкладка «История» возвращает удалённое.

## Обновление

```
.venv\Scripts\python -m pip install --upgrade --force-reinstall git+https://github.com/senia-glitch/idea-graph.git
```
(на macOS и Linux — `.venv/bin/python`). Идеи и графы лежат в ваших папках и обновление не затрагивает.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| `python` не найден | Переустановите Python с галочкой Add Python to PATH; на macOS и Linux пишите `python3` |
| `git` не найден при установке | Установите Git и откройте терминал заново |
| Порт 8765 занят | Запустите с `--port 0` — выберется свободный |
| В «Настройках» агент не подключается | Проверьте, что `claude` или `opencode` запускается в терминале и вы в нём вошли в учётную запись |
| Не хватает лимита модели | Выберите другую модель в «Настройках» или подождите обновления лимита |

## Из чего состоит

| Репозиторий | Что делает | Нужна модель |
|---|---|---|
| [idea-graph-core](https://github.com/senia-glitch/idea-graph-core) | Ядро графа: карточки, связи, операции, журнал, отмена | нет |
| [idea-graph-shell](https://github.com/senia-glitch/idea-graph-shell) | Оболочка: холст, чат, вопросы с вариантами, настройки агентов | нет |
| [idea-graph-clarify](https://github.com/senia-glitch/idea-graph-clarify) | Уточнение идеи: один вопрос за ход | да |
| [idea-graph-check](https://github.com/senia-glitch/idea-graph-check) | Проверка графа: противоречия, дубли, пробелы | частично |
| [idea-graph-decider](https://github.com/senia-glitch/idea-graph-decider) | Решатель: отвечает на вопросы вместо вас | да |
| [idea-graph-composer](https://github.com/senia-glitch/idea-graph-composer) | Компоновщик: карта пакетов и прогон по ней | нет |
| [idea-graph-export](https://github.com/senia-glitch/idea-graph-export) | Выгрузка графа в `idea.md` | нет |
| [idea-graph-research](https://github.com/senia-glitch/idea-graph-research) | Исследование: конкуренты и факты из сети | да |
| [idea-graph-formalize](https://github.com/senia-glitch/idea-graph-formalize) | Формализация: решения → требования | да |
| [idea-graph-handoff](https://github.com/senia-glitch/idea-graph-handoff) | Передача в pacage-studio-ide | нет |

Каждая часть — отдельный Python-пакет, который можно ставить и развивать самостоятельно
(`pip install git+https://github.com/senia-glitch/idea-graph-<имя>.git`; ядро нужно всегда).
Принятые при проектировании решения: [docs/ПРОЕКТ.md](docs/ПРОЕКТ.md).
Свой пакет добавляется через точку входа `ideagraph.packages`; пример — `idea-graph-clarify`.
